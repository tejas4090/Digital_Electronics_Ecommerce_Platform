# Online Shopping Platform

## Description
The Online Shopping Platform is a web-based application developed using Python and Flask. It allows customers to browse products, add items to the cart, place orders, and manage purchases. The administrator can manage products, categories, and orders.

## Features
- User Registration and Login
- Product Management
- Shopping Cart
- Order Placement
- Order History
- Admin Dashboard

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQL

## Project Structure
```
online_shopping/
│── app.py
│── database.sql
│── requirements.txt
│── static/
│── templates/
```

## How to Run
1. Install Python.
2. Install required packages:
   ```
   pip install -r requirements.txt
   ```
3. Run the application:
   ```
   python app.py
   ```
4. Open the application in your browser.
