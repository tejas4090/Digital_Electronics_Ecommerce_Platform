# 🛒 Digital Electronics E-Commerce Platform

A web-based Digital Electronics E-Commerce Platform developed using **Python, Flask, MySQL, HTML, CSS, and JavaScript**. The system allows users to browse electronic products, add them to the cart, place orders, and manage their profiles, while providing an admin panel to manage products and orders.

---

## 🚀 Features

### 👤 User Features
- User Registration & Login
- Browse Electronic Products
- Product Search
- Product Images
- Product Details Page
- Product Ratings & Reviews
- Add to Cart
- Buy Products
- Order History
- Track Orders
- User Profile
- Invoice Generation

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Digital-Electronics-Ecommerce.git
```

### 2. Open the Project

```bash
cd Digital-Electronics-Ecommerce
```

### 3. Install Required Packages

```bash
pip install -r requirements.txt
```

### 4. Create MySQL Database

Create a database named:

```
online_shopping
```

Import the SQL file into MySQL.

### 5. Configure Database

Update the MySQL username and password in `app.py`.

Example:

```python
host="localhost"
user="root"
password="your_password"
database="online_shopping"
```

### 6. Run the Project

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
